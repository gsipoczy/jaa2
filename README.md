# Job Application Assistant 2

jaa2 is a job application helper, an agentic workflow created with Python, Langchain, Langgraph and Gradio.

After a one-time preparation, just paste in it a job description, and it creates a personalized CV and Cover Letter, 
taylored for the given company and job. The resulting documents are ready to send to the target company.

Highlights:
- it searches the Internet for information about the company and uses it to write the motivation, why do you want to work exactly at this company.
- LLM competition: configure teams of LLM models, one writer and one coach. The writer writes the document, the coach reviews and sends back for improvement (reflection cycles).
- a final judge collects the best document parts and compiles the final documents.

Read the JAA2 Manual.pdf for detailed instructions of installation, configuration and usage.
